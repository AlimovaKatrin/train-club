# Очистка всей истории занятий

Скрипт удаляет **все сохранённые занятия: зал, бокс и пилатес**, включая записанные упражнения, рабочие и разминочные подходы. Используются таблицы `session_sets`, `session_exercises`, `sessions`.

Справочник упражнений, программы и планы подходов сохраняются. **Очередь активной программы возвращается к тренировке №1.** Неактивные программы не меняются. После очистки предыдущие результаты упражнений больше не отображаются.

## Запуск

Нужны Node.js 24 и установленные зависимости. Подключение берётся из `DATABASE_URL` в `.env.production.local`. Переменная `DATABASE_URL` терминала и `.env.local` автоматически не используются.

```sh
# Только показать количество занятий, упражнений и подходов для удаления:
npm run db:history:clear

# Удалить всю историю и вернуть очередь к тренировке №1:
npm run db:history:clear -- --apply
```

Для другого файла подключения:

```sh
npm run db:history:clear -- --check --env-file=/absolute/path/database.env
npm run db:history:clear -- --apply --env-file=/absolute/path/database.env
```

Режим по умолчанию и `--check` ничего не изменяют. `--apply` удаляет записи и сбрасывает очередь одной транзакцией: при ошибке откатываются и удаления, и сброс номера. Повторный запуск на пустой истории возвращает нулевые количества; если очередь уже на №1, программа не меняется. Если история пуста, но номер другой, он всё равно сбрасывается. Скрипт не создаёт резервную копию; после успешного удаления восстановление возможно из ранее сделанной копии базы.

На время запуска останови запись занятий в приложении. Блокировки защищают саму транзакцию, но после её завершения приложение снова может сохранять записи. При очистке непустой истории или сбросе номера увеличивается версия активной программы: старые черновики зала больше не соответствуют очереди, нужно начать новое занятие. Черновики в браузере скрипт не удаляет; сохранение черновиков бокса и пилатеса может снова создать записи. Открытые экраны истории нужно обновить.

Скрипт не запускает миграции и ожидает уже созданную схему Train Club. Результат `sessions` — число занятий, `exercises` — число записей выполненных упражнений, `sets` — число подходов; `activities` показывает разбивку занятий по видам. `workoutPosition` показывает номер тренировки до и после сброса (в режиме проверки — планируемого). Если активной программы нет, значение — `null`.
