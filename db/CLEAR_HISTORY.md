# Очистка всей истории занятий

Скрипт удаляет **все сохранённые занятия: зал, бокс и пилатес**, включая записанные упражнения, рабочие и разминочные подходы. Используются таблицы `session_sets`, `session_exercises`, `sessions`.

Справочник упражнений, программы, планы подходов, активная программа и текущий номер тренировки сохраняются. Очередь не возвращается к тренировке №1. После очистки предыдущие результаты упражнений больше не отображаются.

## Запуск

Нужны Node.js 24 и установленные зависимости. Подключение берётся из `DATABASE_URL` в `.env.production.local`. Переменная `DATABASE_URL` терминала и `.env.local` автоматически не используются.

```sh
# Только показать количество занятий, упражнений и подходов для удаления:
npm run db:history:clear

# Удалить всю историю из указанной базы:
npm run db:history:clear -- --apply
```

Для другого файла подключения:

```sh
npm run db:history:clear -- --check --env-file=/absolute/path/database.env
npm run db:history:clear -- --apply --env-file=/absolute/path/database.env
```

Режим по умолчанию и `--check` ничего не изменяют. `--apply` удаляет записи одной транзакцией: при ошибке все удаления откатываются. Повторный запуск на пустой истории возвращает нулевые количества. Скрипт не создаёт резервную копию; после успешного удаления восстановление возможно из ранее сделанной копии базы.

На время запуска останови запись занятий в приложении. Блокировки защищают саму транзакцию, но после её завершения приложение снова может сохранять записи. Черновики в браузере скрипт не очищает: их последующее сохранение создаст записи в истории. Открытые экраны истории нужно обновить.

Скрипт не запускает миграции и ожидает уже созданную схему Train Club. Результат `sessions` — число занятий, `exercises` — число записей выполненных упражнений, `sets` — число подходов; `activities` показывает разбивку занятий по видам.
