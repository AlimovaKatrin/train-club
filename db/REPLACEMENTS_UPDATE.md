# Справочник замен для тренировок 1–16 (версия 4)

`db/seeds/replacements-v4.json` хранит согласованный справочник. Скрипт создаёт версию 4 из опубликованной версии 3: копирует все основные упражнения, их планы, названия и примечания тренировок без изменений, а прежние замены полностью заменяет новым списком. Для каждой замены — два рабочих подхода и собственный диапазон повторений или времени.

```sh
# Только проверка (режим по умолчанию):
npm run db:replacements:update -- --check

# Создать и активировать версию 4:
npm run db:replacements:update -- --apply
```

Подключение читается из `.env.production.local`. Для другого файла добавь `--env-file=/absolute/path/database.env`; переменная `DATABASE_URL` терминала его не подменяет. Нужна активная версия 3. Первичное наполнение выполняется прежними скриптами последовательно: `db:seed:production`, `db:seed:next-cycle`, `db:workouts:update`, затем этот скрипт.

Версия 4 сохраняет текущий номер занятия, 16 тренировок и повтор с №9 после №16. Идентификаторы существующих упражнений используются повторно; новые варианты добавляются отдельно. Мост со штангой на полу отличается от хип-траста в тренажёре. Односторонняя и двусторонняя тяги, наклонный жим для груди и жим над головой имеют разные записи. Обратная «бабочка» отмечена как частичная замена face pull.

Замены привязываются только к основному упражнению каждого места; замены замен рекурсивно не добавляются. Правила для болгарского сплит-приседа, обычной планки и обратной замены сгибания ног лёжа сохранены в справочнике, но не создают дополнительных мест в текущих тренировках. Разгибание рук на верхнем блоке сохраняет прежнее основное название; прямую и V-образную рукояти можно выбрать отдельно вместо каната.

Скрипт по умолчанию выполняет транзакцию только для чтения. При `--apply` блокирует конкурирующее обслуживание и запись занятий, создаёт программу, сверяет исходные шаблоны и полное содержимое истории, затем атомарно переключает активную версию. При ошибке всё откатывается. Повторный запуск сверяет версию 4 без изменений и не сбрасывает очередь.

Перед применением на проде сделай зашифрованную резервную копию `./ops/backup.sh`. Доставь `scripts/` и `db/` из проверенного коммита в отдельный каталог выпуска и подключи их read-only к сервису `migrate`, использующему роль `train_club_migrate`. Выполни `node scripts/update-replacements.mjs --check`, затем `--apply`, затем повторный `--check`. Проверь активную версию, текущий номер, историю и `/api/bootstrap`. Миграция схемы и пересборка приложения для этого изменения данных не нужны.

После переключения обнови страницу. Старый несохранённый черновик потребуется начать заново; редактирование сохранённых занятий остаётся доступным. При сохранении замены приложение записывает выбранное упражнение и его собственные результаты.
