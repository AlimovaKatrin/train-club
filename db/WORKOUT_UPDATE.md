# Обновление тренировок 3–9 (версия 3)

Состав от 12 ноября 2026 хранится в `db/seeds/workout-update-v3.json`. Для каждого из номеров №3–9 указаны шесть упражнений и два рабочих подхода. Подготовительные подходы отдельно; запас около трёх повторений. Отдых после жимов, приседаний и основных тяг — около двух минут, после остальных упражнений — 60–90 секунд. В односторонних упражнениях один подход включает обе стороны.

Скрипт использует справочник и прежние замены из `next-cycle.json`, добавляет разгибание рук на верхнем блоке и жим Палоффа. Для face pull в изменённых тренировках отдых 60–90 секунд. Номера №1–2 и №10–16 копируются без изменений вместе с вариантами и планами.

## Запуск

```sh
# Проверка без записи, подключение из .env.production.local:
npm run db:workouts:update

# Создать и активировать версию 3:
npm run db:workouts:update -- --apply

# Тот же режим через исходный генератор:
npm run db:seed:next-cycle -- --update-3-9 --apply
```

Для другого подключения добавь `--env-file=/absolute/path/database.env`. Переменная `DATABASE_URL` терминала не подменяет выбранный файл.

Необходима активная опубликованная версия 2 «Силовые · 16 тренировок». Новая версия сохраняет текущий номер, количество тренировок и правило возврата после №16. Сохранённая история, её снимки и предыдущие результаты упражнений не изменяются. Идентификаторы уже известных упражнений используются повторно. Старая версия остаётся в базе неактивной; опубликованные шаблоны не переписываются.

Перед обновлением заверши текущий черновик либо начни занятие заново после переключения. Черновики старой версии остаются в браузере, но сохранить их как новые занятия после переключения нельзя. Редактирование уже сохранённой истории доступно.

Копирование, добавление новых упражнений, проверки и переключение выполняются одной транзакцией. Скрипт сверяет полное содержимое истории до и после, а также неизменность исходных шаблонов. При ошибке всё откатывается. Повторный запуск проверяет уже созданную версию и не сбрасывает очередь.

## На собственном сервере

Используй роль `train_club_migrate` через `.env.migrations.local` и существующий одноразовый сервис `migrate`. Создай резервную копию `./ops/backup.sh` перед применением. Если обновлённые `scripts/` и `db/` доставлены в отдельный каталог выпуска, их можно подключить к контейнеру мигратора read-only и запустить `node scripts/update-workouts.mjs --check`, затем `--apply`. Новая схема базы и пересборка приложения для этого обновления данных не требуются.

После применения проверь активную версию 3, сохранение текущего номера, две рабочие серии во всех новых упражнениях, сохранность истории и здоровье `/api/bootstrap`.
