# Иллюстрации техники

Документы серии:

- [Требования к картинкам и процессу генерации](REQUIREMENTS.md) — образ героини, композиция, техника, формат файлов, порядок проверки и подключения.
- [Каталог всех 28 упражнений](CATALOG.md) — какие картинки подключены, какие требуют правки и какие ещё не созданы; ссылки на файлы.
- [Архитектура хранения и отображения](../../ARCHITECTURE.md#21-иллюстрации-техники-упражнений) — связь с ID упражнения, файлы в Git и Docker, показ в интерфейсе, обновление и восстановление.

Каталог прочитан из рабочей базы 12 ноября 2026 года: 28 упражнений, включая замены.
Генерация приостановлена по просьбе пользователя после 13 изображений.

- 12 изображений подключены через `src/lib/exercise-images.ts` по постоянному ID упражнения.
- «Мёртвый жук» сохранён в `drafts/`, не подключён: в последнем варианте вытянуты рука и нога с одной стороны. Нужны противоположные конечности и повторная проверка исходного положения.
- Для оставшихся 15 упражнений изображения пока не созданы; текст техники продолжает отображаться.

Образ по запросу пользователя: взрослая женщина soft masc с короткой стрижкой и татуировками, свободная спортивная футболка и шорты. Светлый фон, зелёная палитра приложения, две фазы движения. Референс персонажа — `originals/goblet-squat.png`.

Использован встроенный `image_gen`: отдельный вызов на каждое упражнение и дополнительные правки после визуального просмотра. `prompts.json` содержит исходные задания для всей серии; `manifest.json` — статус, итоговые промпты и внесённые коррекции. Это визуальная проверка иллюстраций, а не независимая профессиональная проверка техники.

Исходники сохранены в `originals/`. Для приложения они конвертированы в WebP (quality 88, без изменения размеров 1536 × 1024), файлы находятся в `public/exercises/`. Каталог с исходниками исключён из Docker-сборки.

В интерфейсе картинки находятся в закрытом по умолчанию блоке «Техника и прошлый результат». Нажатие открывает полноэкранный просмотр на телефоне; доступно увеличение ×2 с прокруткой. Закрытие кнопкой или Escape возвращает фокус и сохраняет введённый подход. При отсутствии или ошибке загрузки картинки остаются текстовые инструкции. Смена упражнения или замены выбирает иллюстрацию по `exerciseId`, а не по названию или ID пункта программы.

Продолжение серии: взять упражнение со статусом `not-generated`, использовать референс персонажа, проверить позы и оборудование, сохранить оригинал, сконвертировать WebP и добавить стабильный ID в карту. Черновики со статусом `needs-correction` сначала исправить.
