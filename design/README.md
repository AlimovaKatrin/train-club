# Train Club — дизайн-концепт 01

Основа: бизнес-требования из чата TZ, включая последние уточнения от 8 ноября 2026. Это кликабельный набросок мобильного веб-интерфейса, не готовый сервис учёта тренировок.

Открыть `index.html` в браузере. Файл самодостаточный, не требует сборки, интернета или установки приложения. `overview.png` — визуальный обзор четырёх экранов; `overview.html` собирает его из скриншотов.

## Визуальное решение

- Молочный фон #F6F5EF, шалфейные поверхности #DFE7DA, зелёные действия #456752, графитовый текст #293C33.
- Спокойные заголовки Georgia и системный шрифт интерфейса. Без внешних шрифтов и фотографий.
- Одна мобильная колонка: основной viewport 402 × 874 CSS px, ширина страницы не больше 440 px. На компьютере сохраняется мобильная композиция.
- Закреплённое главное действие, учёт safe-area, числовая клавиатура, ручной ввод и кнопки ±. Никакой имитации статус-бара или Dynamic Island: это страница внутри браузера.

## Экраны и сценарии

1. Сегодня: зал, пилатес или бокс; следующая тренировка блока из восьми. Номера блока не переключаются вручную.
2. Перед занятием: дата, самочувствие 0–5, часы сна (по умолчанию 8, можно изменить).
3. Тренировка: прошлые результаты, веса и повторения, секунды для планки, рабочие подходы и отдельная необязательная разминка перед первым рабочим, копирование предыдущего рабочего подхода. Разминка выбирается только на первом подходе до выполнения рабочих, сохраняется отдельной плашкой в табах и не входит в счётчик. После разминки остаются все плановые рабочие подходы; плашка позволяет просмотреть и исправить разминку.
4. Замены: нижняя панель с примерами альтернатив для первой тяги. Вес не переносится; замена действует только в текущем занятии. Остальные упражнения показывают состояние без заданных замен.
5. Итоги: для зала — отдельные минуты разминки, основной части, кардио и общая сумма; для бокса и пилатеса — фиксированный час без ввода времени; минимальный/максимальный пульс (по умолчанию 100–180, можно изменить); тяжесть 0–10; заметка.
6. Подтверждение и история: фильтры по виду, просмотр записи и исправление подходов/итогов. Редактирование не двигает очередь зала.

## Границы наброска

Все упражнения, замены, даты и результаты — явно обозначенные демонстрационные данные. Состав программы тренером ещё не утверждён. Макет показывает один пример тренировки и движение очереди, а не восемь готовых комплексов.

Данные существуют только в памяти открытой страницы и сбрасываются при перезагрузке. База данных, авторизация, SQL-загрузка программ и перенос Google-истории не реализованы. Автосохранения черновиков нет. Шаги, запас повторений, автоматические рекомендации и редактор программ не добавлены.

В наброске можно завершить занятие с незаписанными подходами: история сохраняет их как «не записан», без выдуманных значений. Замена после уже записанных подходов пока недоступна. Полная правка даты/самочувствия исторической записи не реализована.

## Проверка

Проверены переходы и снимки экранов в Chromium с мобильным viewport 402 × 874; главная, подготовка и история — также на 320, 375 и 440 px. Пройдены сценарии валидации начала занятия, замены, копирования подхода, проверки пульса, сохранения, изменения истории и независимости пилатеса от очереди зала. Ошибок JavaScript в проверенном прогоне нет. Проверка на физическом iPhone и в Safari не проводилась.
